# AI-Powered Paraphrasing Tool

## Project Overview
This project develops an AI-powered paraphrasing tool using Python and a pretrained T5 Transformer model. It generates alternative versions of input text while attempting to preserve the original meaning.

## Technologies Used
- Python
- Google Colab
- Hugging Face Transformers
- PyTorch
- LanguageTool
- NLTK
- ROUGE
- Sentence Transformers

## Features
- Accepts user input.
- Generates paraphrased text using T5.
- Checks grammar and spelling.
- Evaluates semantic similarity.
- Provides console-based interaction.

## Evaluation Results
- Sentences tested: 5
- Average semantic similarity: 0.9922
- Average similarity percentage: 99.22%

Note: The model sometimes produces outputs with limited wording changes.

## Conclusion
The project demonstrates the use of Deep Learning and Natural Language Processing to build an automated paraphrasing application. Further improvements can enhance paraphrasing quality and originality.

## How to Run
1. Open the notebook in Google Colab.
2. Install the required libraries.
3. Load the pretrained T5 model.
4. Run the notebook cells in order.
5. Enter text and view the paraphrased output.
